# SeamOS Hackathon Template — Setup

This is a SeamOS C++ app template (FD flat layout). Linux / macOS.

## 1. Clone & bootstrap

```bash
git clone <repo-url> && cd <repo>
bash scripts/seamos-bootstrap.sh
```

`seamos-bootstrap.sh` regenerates `.seamos-context.json` (gitignored — it
embeds absolute paths that differ per machine) and runs `npm install`
inside `customui-src/` if needed.

## 2. Open in seamos-ide

Open the cloned folder in **seamos-ide** and run **Import / full build**.
The IDE regenerates the layers that are intentionally NOT committed:
`com.bosch.fsp.*.gen/`, `com.bosch.fsp.*.gen.tests/src/`,
`<app>_CPP_SDK/src-gen/`, and re-extracts the SDK runtime from
`<app>_CPP_SDK/dependencies/INSTALL_x86_64.tar.xz`.

Requires **JDK 21** on PATH (the test simulator is compiled to Java 21).

## 3. CustomUI

UI source of truth is `customui-src/` (React). Build deploys into
`<app>/ui/` (gitignored):

```bash
cd customui-src && npm run build
```

Never edit `<app>/ui/` directly — it is build output.

## 4. Claude Code plugin (optional, recommended)

`.claude/settings.json` enables the **seamos-everywhere** plugin
(build-fif, run-app, upload-app, …). On first `claude` run in the folder,
approve the workspace-trust and marketplace prompts; the plugin installs
automatically. Verify with `/plugin` and `/plugin marketplace list`.

## What's committed vs regenerated

| Committed | Regenerated by IDE / build (gitignored) |
|---|---|
| FSP source `com.bosch.fsp.<name>/` | `*.gen/`, `*.gen.tests/src/` |
| App user code `<app>_<app>/` (Manifest, src-gen user code, config) | `build/`, `out/`, `bin/`, `target/` |
| `customui-src/` source | `customui-src/node_modules`, `dist`, `<app>/ui/*` |
| `*.gen.tests/testlib/*.jar`, metadata | `<app>_CPP_SDK/src-gen`, `/build`, `/dependencies/{lib,include}` |
| `<app>_CPP_SDK/dependencies/INSTALL_x86_64.tar.xz` | runtime dirs `disk/ in/ out/ logs/ backup/` |
| `.claude/settings.json`, `.mcp.json`, `.seamos-workspace.json` | `.seamos-context.json` (machine-specific) |
